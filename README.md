## Projects

- **[ArSen_AI](https://github.com/AlenGevorgyan/ArSen_AI)**: real-time translator from Armenian Sign Language to text. Webcam, MediaPipe hand landmarks and an LSTM network. Runs on a CPU. Recognizes single words for now.
- **[OCArm](https://github.com/AlenGevorgyan/OCArm)**: OCR for handwritten Armenian. Takes a photo and returns text or a file (TXT, PDF, CSV, Excel). FastAPI back end and a web front end.
- **[ml-internship-codveda](https://github.com/AlenGevorgyan/ml-internship-codveda)**: two end-to-end ML tasks from my internship at Codveda Technologies: a tuned Random Forest for customer churn and a neural network for MNIST.
